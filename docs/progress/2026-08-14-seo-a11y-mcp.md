**Gejala:** user mengunggah PDF berkali-kali, CV tidak berubah.

**Akar:** `CVGenerator` menghidrasi form dari CV sekali lalu keluar dari

menyimpan editan yang belum sampai server, dihapus begitu save sukses.

### Build harus bertahan saat Convex mati

Setiap pembacaan Convex baru menulis "degrade instead of failing the build" lalu
memasang try/catch **tanpa deadline**. Catch tidak bisa menyala pada request yang
tidak pernah kembali: `next build` mencetak *"took more than 60 seconds"* untuk
`/`, `/dokumen`, `/roadmap`. Dokploy build langsung dari push, jadi itu artinya
blip backend = deploy gagal.

`frontend/shared/lib/publicContentQuery.ts` mengikat semuanya dengan **dua**
batas: abort signal di fetch, dan race di await. Batas yang hanya menutup bagian
yang kamu duga bukan batas.

## 4. Soft-404 di seluruh ruang URL

`careerpack.org/apa-pun` menjawab **HTTP 200** dengan badan "Profil tidak
ditemukan", ber-`cache-control: s-maxage=60, stale-while-revalidate=31535940`.
`app/[slug]` adalah catch-all root, jadi itu **setiap URL yang ada**.

**Akar:** `app/[slug]/loading.tsx`. File loading di sebuah segmen membuat Next
membungkusnya dengan Suspense dan mem-flush shell segera; flush mengunci baris
status, jadi `notFound()` beberapa frame kemudian tidak bisa mengubahnya.

Menghapus file itu adalah seluruh perbaikannya. `slug-route-status.test.ts`
gagal kalau ada yang mengembalikannya — regresi ini tidak terlihat dari tiga
arah sekaligus (menambah skeleton terbaca sebagai perbaikan UX, `next build`
tetap normal, dan tidak ada test lain yang memeriksa status code).

> **Konsekuensi yang dibiarkan:** `force-static` pada segmen yang dikendalikan
> pengunjung berarti tiap slug berbeda yang diprobe meninggalkan ~44 KB di cache
> server, tanpa batas jumlah. Itu harga desain checkpoint §5 di file yang sama
> (cache menyerap enumerasi supaya tidak menembus Convex).

## 6. Aksesibilitas — publik lalu dashboard

**Publik (12 halaman × 3 viewport):** 60 → **0** pelanggaran axe.

Tiga masalah, tiga akar tunggal:
- **Kontras**: token `--brand`/`--primary` L 0.62 = 3,72:1. Dipakai sebagai
  warna teks **dan** isian tombol, jadi gagal dua arah. L 0.56 → 4,79:1.
- **Teks kecil**: `--font-scale` default `compact` (0.92) menjatuhkan `text-xs`
  ke 11,04px. Dipasang lantai 12px pada satu langkah itu, bukan menaikkan skala
  global.
- **Link tanpa nama**: label `hidden xs:inline`, dan **`xs` bukan breakpoint**
  di `tailwind.config.ts` — hanya key borderRadius/shadow. Tidak pernah cocok di
  lebar mana pun.

**Dashboard (17 rute × 2 viewport):** 155 → **52** node.

| Aturan | Awal | Akhir |
|---|---|---|
| `nested-interactive` | 10 | **0** |
| `button-name` (kritis) | 2 | **0** |
| `link-name` | 6 | **0** |
| `aria-progressbar-name` | 2 | **0** |
| `scrollable-region-focusable` | 2 | **0** |
| `color-contrast` | 52 | 52 |

`text-[10px]`/`text-[11px]` muncul **211 kali** — nilai arbitrer tidak pernah
menjadi `.text-xs`, jadi lantai 12px tidak bisa menjangkaunya. 1.011 → 27
elemen.

> **Temuan sistemik yang belum disapu:** `--font-scale` 0.92 menskalakan basis

> yang dipatok pas di batas WCAG 2.5.8 otomatis jatuh di bawahnya.

harus lewat `node .next/standalone/frontend/server.js`; kalau tidak, angkanya
